# Sound effect licenses

Every file in this folder comes from a source released under **CC0 1.0 Universal (Public Domain Dedication)**:
https://creativecommons.org/publicdomain/zero/1.0/ (legal code: https://creativecommons.org/publicdomain/zero/1.0/legalcode)

CC0 allows commercial use, modification and redistribution, including inside a SaaS product or tool, and it **does not require attribution**. The credits below are kept for provenance only. They are optional.

The license was checked on each item's source page on 2026-10-18. For Freesound, each page shows "Creative Commons 0" with a link to the CC0 1.0 deed. Each page's description was also read to rule out sounds that sample non-CC0 material. For Kenney, the asset page shows "Creative Commons CC0" and the `License.txt` bundled in the pack says "License: (Creative Commons Zero, CC0) ... free to use in personal, educational and commercial projects ... crediting Kenney ... is not mandatory".

## Processing applied

- Freesound items were taken from the public high-quality MP3 preview (128 kbps) of each CC0 sound. The CC0 license covers the sound in every format.
- All files were converted to MP3 at 160 kbps and 44.1 kHz. Leading and trailing silence was trimmed, and each file was peak-normalized to -1 dBFS (so set per-sound volume in the app). Short fades were added. A few longer sounds were cut down (noted below).
- The metadata of the source files was removed.

## Sources considered and not used

- **Mixkit (Sound Effects Free License).** The license text (https://mixkit.co/license/#sfxFree) says: "You can't redistribute the Item on its own, as stock, in a tool or template, or with source files." A subtitle editor that offers the sounds to its users is a tool, so this license does not fit.
- **Pixabay (Content License).** It prohibits distributing Content "on a Standalone basis", meaning unmodified (https://pixabay.com/service/terms/). It also prohibits using or compiling Content "to replicate a similar or competing service". Serving unmodified SFX files to users from an in-app library is a gray area, so CC0 sources were used instead.
- **Freesound items rejected despite a CC0 tag:**
  - "Cash Register Purchase" by Zott820 (#209578). Its description says it includes a CC-BY 4.0 source.
  - "Ding.wav" by chennes (#376807). It is based on a sound from a commercial game.
  - "cash register chching" by disman (#728224). Its origin is unclear.
