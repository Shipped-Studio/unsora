---
title: "Get clipping job"
description: "Fetch a single AI clipping job by ID with its status, source video, and the list of generated clips with captions and timestamps."
openapi: "GET /clippings/{clippingId}"
---

Returns the job and its clips **without** syncing with the provider. Use [Poll status](/api-reference/clippings/poll-status) while a job is processing.

**`GET /clippings/{clippingId}`**

## Path parameter

<ParamField path="clippingId" type="string" required>
  Job id from [Create](/api-reference/clippings/create) or [List](/api-reference/clippings/list).
</ParamField>

## Example

```bash
curl "https://mvp.tryunsora.com/api/v1/clippings/CLIPPING_ID" \
  -H "Authorization: Bearer uns_YOUR_API_KEY"
```
