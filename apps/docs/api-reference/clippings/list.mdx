---
title: "List clipping jobs"
description: "Paginated list of all AI clipping jobs for the authenticated user, including status, source videos, and generated clips."
openapi: "GET /clippings/all"
---

**`GET /clippings/all`**

## Response

```json
{
  "success": true,
  "data": [
    {
      "id": "clip_job_123",
      "status": "COMPLETED",
      "videoUrl": "https://example.com/long-form.mp4",
      "error": null,
      "createdAt": "2026-06-02T12:00:00.000Z",
      "updatedAt": "2026-06-02T12:05:00.000Z",
      "clips": [
        {
          "id": "clip_1",
          "order": 0,
          "outputAsset": { "url": "https://files.tryunsora.com/....mp4" }
        }
      ]
    }
  ]
}
```

## Example

```bash
curl "https://mvp.tryunsora.com/api/v1/clippings/all" \
  -H "Authorization: Bearer uns_live_YOUR_API_KEY"
```
