---
title: "Get accounts"
description: "List every social account connected to your Unsora workspace for scheduling — YouTube, TikTok, Instagram, Facebook, LinkedIn, Bluesky, and more."
openapi: "GET /accounts"
---

Returns social accounts connected to the authenticated user. Use each account `id` when calling [Create Post](/api-reference/posts/create_post).

Supported platforms: **YouTube, TikTok, Instagram, Facebook, LinkedIn,
Bluesky, Threads, Pinterest**. Each account's `provider` field identifies its
platform — YouTube accounts have provider `google`.

```bash
curl "https://mvp2.tryunsora.com/api/v1/accounts" \
  -H "Authorization: Bearer uns_YOUR_API_KEY"
```

Example response:

```json
{
  "success": true,
  "data": [
    {
      "id": "cm123abc",
      "provider": "instagram",
      "providerAccountId": "...",
      "accountName": "My Page",
      "accountUsername": "mypage",
      "profilePicture": "https://...",
      "expiresAt": "2026-12-01T00:00:00.000Z"
    },
    {
      "id": "cm456def",
      "provider": "tiktok",
      "providerAccountId": "...",
      "accountName": "My TikTok",
      "accountUsername": "mytiktok",
      "profilePicture": "https://...",
      "expiresAt": "2026-12-01T00:00:00.000Z"
    }
  ]
}
```

`provider` values include `instagram` and `tiktok`.
