---
title: "List voiceovers"
description: "Paginated history of voiceover jobs for the authenticated user, including script, voice, status, and finished audio files."
openapi: "GET /voiceovers/all"
---

Returns the authenticated user's voiceover jobs, newest first.

```bash
curl "https://mvp.tryunsora.com/api/v1/voiceovers/all?page=1&limit=12" \
  -H "Authorization: Bearer uns_YOUR_API_KEY"
```
