---
title: "Delete thumbnail"
description: "Permanently delete a thumbnail generation and its images from your Unsora account. This action cannot be undone."
openapi: "DELETE /thumbnails/{generationId}"
---

**`DELETE /thumbnails/{generationId}`**

## Path parameter

<ParamField path="generationId" type="string" required>
  Thumbnail id from [Create](/api-reference/thumbnails/create) or [List](/api-reference/thumbnails/list).
</ParamField>

## Response

```json
{
  "success": true,
  "message": "Generation deleted successfully"
}
```

## Example

```bash
curl -X DELETE "https://mvp.tryunsora.com/api/v1/thumbnails/GENERATION_ID" \
  -H "Authorization: Bearer uns_live_YOUR_API_KEY"
```
